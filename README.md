# Nabeman.ir

**نابِ ما؛ نه به منیت، آری به همدلی.**

این مخزن فقط برای سایت **Nabeman.ir** و میزبانی آن در **Tetrahost** است. با مخزن دولت عشق (dolate_eshgh) و هاست InfinityFree تفاوت دارد.

## هدف

Nabeman.ir — نه به منیت و خودکامگی؛ آری به همدلی، خرد جمعی و مشارکت همگانی در مسیر دولت عشق.

## انتشار امن

- انتشار فقط با اجرای دستی GitHub Actions انجام می‌شود.
- گردش‌کار فقط فایل‌های جدید/تغییرکرده را به Tetrahost بارگذاری می‌کند.
- هیچ گزینه حذف فایل از هاست (--delete) وجود ندارد؛ فایل‌های موجود روی هاست به‌طور خودکار حذف نمی‌شوند.
- فایل‌های رایج تنظیمات محرمانه، دیتابیس، پشتیبان و فایل‌های README/workflow از بارگذاری مستثنا هستند.
- پیش از اولین انتشار، فایل‌های واقعی سایت را به این مخزن اضافه و فایل‌های تنظیمات/رمزها را بررسی کنید.

راهنمای اتصال و انتشار: [راهنمای Tetrahost](docs/tetrahost-deployment.md)
