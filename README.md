# Nabeman.ir

**نابِ ما؛ نه به منیت، آری به همدلی.**

این مخزن فقط برای سایت فعال **Nabeman.ir** روی **Tetrahost** است. با مخزن دولت عشق (dolate_eshgh) و هاست InfinityFree تفاوت دارد.

## هدف

Nabeman.ir — نه به منیت و خودکامگی؛ آری به همدلی، خرد جمعی و مشارکت همگانی در مسیر دولت عشق.

## مدیریت سایت فعال با GitHub

- سایت قبلاً روی Tetrahost منتشر شده و فعال است؛ این مخزن برای مدیریت و به‌روزرسانی همان سایت موجود ساخته شده است.
- پیش از اولین انتشار از GitHub، نسخه فعلی فایل‌های سایت را از Tetrahost دریافت و در مخزن قرار دهید تا نسخه زنده ناخواسته با فایل‌های ناقص جایگزین نشود.
- انتشار فقط با اجرای دستی GitHub Actions انجام می‌شود.
- گردش‌کار فایل‌های جدید/تغییرکرده را بارگذاری می‌کند و از حذف خودکار فایل‌های هاست استفاده نمی‌کند.
- توجه: اگر فایل هم‌نامی در مخزن و هاست وجود داشته باشد، فایل مخزن می‌تواند فایل هاست را بازنویسی کند؛ بنابراین ابتدا باید نسخه زنده همگام شود.
- فایل‌های محرمانه، تنظیمات اتصال دیتابیس، پشتیبان‌ها و فایل‌های README/workflow از بارگذاری مستثنا هستند.

راهنمای همگام‌سازی و انتشار: [راهنمای Tetrahost](docs/tetrahost-deployment.md)

## شاخه آزمایشی انتقال دولت عشق

- کد برنامه دولت عشق در شاخه `import/dolate-eshgh-base` به‌عنوان مبنای فنی ناب من وارد شده است.
- این شاخه هنوز برای انتشار روی Tetrahost تأیید نشده است.
- فایل واقعی `db.php` عمداً وارد GitHub نشده؛ اتصال دیتابیس باید جداگانه و فقط روی هاست تنظیم شود.
- راهنمای امن اتصال دیتابیس: [راهنمای دیتابیس Tetrahost](docs/tetrahost-database-setup.md)
- فایل‌های نمونه و راهنما داخل پوشه `docs` هستند و گردش‌کار انتشار آن‌ها را بارگذاری نمی‌کند.
- پیش از هر انتشار، باید نسخه فعلی سایت زنده با این شاخه مقایسه و پشتیبان‌گیری شود.
