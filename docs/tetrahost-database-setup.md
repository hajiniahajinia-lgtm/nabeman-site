# آماده‌سازی اتصال دیتابیس Nabeman.ir روی Tetrahost

این راهنما برای شاخه آزمایشی `import/dolate-eshgh-base` است. هنوز هیچ تغییری روی سایت زنده انجام نشده است.

## نکته امنیتی
- فایل واقعی `db.php` نباید در GitHub قرار بگیرد.
- رمز دیتابیس را در پیام، GitHub، README یا فایل عمومی وارد نکنید.
- فایل `docs/db.php.example` فقط الگو است و رمز واقعی ندارد.
- پس از تکمیل تنظیمات، از انتشار فایل نمونه به‌جای فایل واقعی خودداری کنید.

## اطلاعاتی که باید از cPanel گرفته شود
در cPanel بخش **MySQL Databases** یا **Manage My Databases**، این موارد را بررسی کنید:
1. نام دیتابیس کامل
2. نام کاربر دیتابیس کامل
3. اینکه کاربر به دیتابیس دسترسی کامل (All Privileges) دارد
4. نام میزبان MySQL که Tetrahost اعلام کرده است
5. پورت MySQL؛ اگر هاست مقدار دیگری اعلام نکرده، مقدار پیش‌فرض 3306 است.

## ساخت فایل واقعی روی هاست
1. از فایل نمونه، یک کپی با نام `db.php` در ریشه سایت بسازید.
2. مقادیر میزبان، نام کاربر، رمز، نام دیتابیس و پورت را فقط در همان فایل روی هاست جایگزین کنید.
3. مطمئن شوید فایل `db.php` در ریشه کنار فایل‌های PHP برنامه قرار دارد.
4. مجوز فایل را روی مقدار پیش‌فرض امن هاست نگه دارید؛ معمولاً 644.

## قبل از اجرا
- هیچ migration یا SQL را روی دیتابیس زنده اجرا نکنید.
- ابتدا باید ساختار و جدول‌های دیتابیس فعلی Nabeman.ir با نیازهای برنامه مقایسه شود.
- فایل‌های migration در این مخزن به‌تنهایی تضمین نمی‌کنند که یک دیتابیس خالی را از صفر بسازند.
- اگر خطای اتصال رخ داد، رمز یا متن کامل خطا را در GitHub یا این گفتگو نفرستید؛ فقط نوع خطا را گزارش کنید.

## وضعیت
این مرحله صرفاً آماده‌سازی مستندات است. تنظیم اتصال واقعی و اجرای SQL هنوز انجام نشده است.
