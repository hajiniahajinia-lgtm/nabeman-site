# همگام‌سازی سایت فعال Nabeman.ir با GitHub و Tetrahost

## وضعیت

سایت Nabeman.ir از قبل روی Tetrahost منتشر و فعال است. هدف این راهنما اتصال مدیریت فایل‌های همان سایت موجود به مخزن خصوصی `nabeman-site` است؛ نه ساخت یا انتشار یک سایت تازه.

## 1. دریافت نسخه فعلی سایت

1. در cPanel/Tetrahost وارد File Manager شوید.
2. پوشه اصلی سایت (معمولاً `public_html`) را باز کنید.
3. فایل‌های فعلی سایت را دانلود کنید و در ریشه مخزن `nabeman-site` قرار دهید.
4. فایل‌های حساس مانند رمز دیتابیس، `.env`، فایل‌های backup و تنظیمات محرمانه را وارد GitHub نکنید. آن‌ها باید روی هاست باقی بمانند.
5. فایل‌های اصلی را بررسی کنید تا نسخه‌ای که در GitHub قرار می‌گیرد با سایت زنده فعلی هماهنگ باشد.

## 2. Secrets برای FTP

در مخزن `nabeman-site` به مسیر Settings → Secrets and variables → Actions → New repository secret بروید و این چهار مقدار را تنظیم کنید:

- `FTP_SERVER`: نام/آدرس سرور FTP از اطلاعات Tetrahost، نه آدرس سایت.
- `FTP_USERNAME`: نام کاربری FTP.
- `FTP_PASSWORD`: رمز FTP.
- `FTP_REMOTE_DIR`: مسیر دقیق پوشه سایت که Tetrahost برای FTP نشان می‌دهد (اغلب `public_html/`؛ مسیر را از پنل تأیید کنید).

این مقادیر را در فایل‌های مخزن یا پیام عمومی قرار ندهید.

## 3. انتشار از GitHub

پس از همگام‌سازی نسخه فعلی و تنظیم Secrets:

1. در مخزن `nabeman-site` زبانه Actions را باز کنید.
2. گردش‌کار **Upload Nabeman site to Tetrahost** را انتخاب کنید.
3. روی **Run workflow** بزنید.
4. پس از پایان موفق، `https://nabeman.ir` را باز کنید و صفحه اصلی و `about.html` را بررسی کنید.

## ایمنی

- گردش‌کار فقط دستی اجرا می‌شود.
- از دستور حذف فایل‌های هاست استفاده نمی‌کند.
- فایل‌های جدید/تغییرکرده را بارگذاری می‌کند.
- اگر فایل هم‌نام در مخزن و هاست وجود داشته باشد، نسخه مخزن ممکن است نسخه هاست را بازنویسی کند. به همین دلیل **قبل از اولین اجرا باید فایل‌های موجود سایت همگام شوند**.
- تا قبل از همگام‌سازی کامل و بررسی فایل‌ها، workflow را اجرا نکنید.
