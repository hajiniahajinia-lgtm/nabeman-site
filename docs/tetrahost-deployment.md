# اتصال امن Nabeman.ir به Tetrahost

## وضعیت فعلی

مخزن Nabeman جدا از مخزن دولت عشق است. انتشار فقط با اجرای دستی انجام می‌شود و فایل‌های هاست را حذف نمی‌کند. تا زمانی که فایل‌های اصلی سایت وارد مخزن و Secrets تنظیم نشده‌اند، انتشار را اجرا نکنید.

## فایل‌های لازم در GitHub

فایل‌های واقعی سایت را از پوشه اصلی سایت در Tetrahost (معمولاً public_html) دریافت و به ریشه این مخزن اضافه کنید. فایل‌های محرمانه مانند رمز دیتابیس، فایل‌های اتصال دیتابیس، .env و نسخه‌های پشتیبان را وارد مخزن نکنید. تنظیمات محرمانه فعلی روی هاست را حفظ کنید.

## افزودن Secrets

در مخزن nabeman-site به مسیر Settings → Secrets and variables → Actions → New repository secret بروید و این چهار Secret را اضافه کنید:

- FTP_SERVER: نام سرور FTP که Tetrahost در پنل ارائه می‌دهد؛ نه آدرس کامل سایت.
- FTP_USERNAME: نام کاربری FTP
- FTP_PASSWORD: رمز FTP
- FTP_REMOTE_DIR: مسیر پوشه سایت در هاست، معمولاً public_html/ یا مسیر کامل ارائه‌شده توسط Tetrahost

مقادیر را در README یا فایل‌های مخزن قرار ندهید.

## اجرای انتشار

پس از بارگذاری فایل‌های سایت و تنظیم Secrets:

1. به زبانه Actions بروید.
2. گردش‌کار Upload Nabeman site to Tetrahost را انتخاب کنید.
3. Run workflow را بزنید.
4. پس از سبز شدن اجرا، سایت را باز و صفحات را بررسی کنید.

این گردش‌کار دستی است و فایل‌ها را فقط بارگذاری می‌کند؛ از دستور حذف فایل‌های موجود روی هاست استفاده نمی‌کند. با این حال، قبل از اجرای نخست، مسیر FTP و فایل‌های سایت را بررسی کنید.
